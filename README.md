<h2 align="center">About</h2>

<p>
I am a Computer Science student exploring the fields of <b>reverse engineering, binary analysis, low-level systems, and software security</b>.
</p>

<p>
My current focus is on understanding how software works beneath the source code — from executable formats and assembly to processes, memory, control flow, and program behavior.
</p>

<p>
I work with programming and low-level technologies while developing my knowledge through hands-on experimentation, personal projects, and continuous study.
</p>

<p>
My interests include <b>reverse engineering, binary analysis, malware analysis, vulnerability research, and software security</b>.
</p>

<p>
I am currently building my foundations in the field while exploring how software can be analyzed, understood, and reconstructed from the machine level up.
</p>
